# 声で原稿（koe-de-genko）

話した内容をその場で文字にして、**そのまま GitHub のフォルダに保存**できる音声メモです。
iPhone・Android・Windows・Mac のブラウザで、インストールなしで使えます。

**▶ 使う：https://hakusyaku-lab.github.io/koe-de-genko/**

Claude Code などの AI に「自分の書き方」を覚えさせるための見本（`samples/`）や、
あとで記事に仕上げてもらう下書き（`inbox/`）を、思いついたときに声で集める用途を想定しています。

## できること

- ボタンを押して話すと文字になる（「改行」「句点」「読点」で 改行・。・、）
- 書きかけはその端末に自動で残る
- 保存先を2つ切り替えられる（初期値は「見本 → samples/」「原稿メモ → inbox/」）
- **GitHubに保存**：GitHub の新規ファイル画面が「ファイル名・本文入り」で開くので、緑の **Commit changes** を押すだけ
- **Claudeに頼む**：原稿と依頼文をまとめてコピーして Claude Code を開く
- **共有・ファイル**：.md ファイルとして共有・保存（スマホは共有メニュー、PCはダウンロード）

パスワードやアクセストークンは使いません。保存は、普段 GitHub にログインしているブラウザ（またはアプリ）で行います。
原稿も設定も、その端末のブラウザの中にだけ保存されます。

## 対応ブラウザ

| 端末 | ボタンで話す | キーボードの音声入力 |
| --- | --- | --- |
| iPhone / iPad | Safari ○ | ○ |
| Android | Chrome・Edge ○ | ○ |
| Windows | Chrome・Edge ○ | ○（Win + H） |
| Mac | Chrome・Edge・Safari ○ | ○ |

Firefox はボタンでの音声認識に対応していません。その場合もキーボードの音声入力で話せば同じように使えます。
Chrome・Edge の音声認識はインターネット接続が必要です。

## はじめに（1回だけ）

1. 上のURLを開き、右上の「設定」で保存先のリポジトリ（例：`hakusyaku-lab/shippitsu-ai`）を入れる
   - URL の後ろに `?repo=持ち主/名前` を付けて開いても設定できます
2. スマホはホーム画面に追加しておくと、アプリのように開けます
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「ホーム画面に追加」
3. 最初に話すとき、マイクの使用を「許可」する

## 長い原稿のとき

GitHub の画面に本文を入れて開ける長さには限りがあります。長い原稿は自動でコピーされるので、
開いた画面の本文欄に貼り付けてから **Commit changes** を押してください。
