設定はこの端末のブラウザにだけ保存されます。パスワードやトークンは使いません。

使い方

1. 話す：「タップして話す」を押して話します。もう一度押すと止まります。「改行」「句点」「読点」で改行・。・、が入ります。

2. 直す：文字はそのまま手で直せます。書きかけは自動でこの端末に残ります。

3. 保存：保存先（見本／原稿メモ）を選んで「GitHubに保存」。GitHubの保存画面が中身入りで開くので、緑の「Commit changes」を押せば保存完了です（GitHubにログインしている必要があります）。

見本は執筆AIに書き方を覚えさせるための自分の文章、原稿メモはあとでAIに記事などへ仕上げてもらう下書きです。

「Claudeに頼む」は、原稿と依頼文をまとめてコピーして Claude Code を開きます。チャット欄に貼り付けて送ってください。

ボタンで話せるのは Chrome・Edge・Safari です。使えないときは、キーボードのマイク（音声入力）で話しても同じように使えます。
